## 1. 背景与问题

重构前实例列表同时展示组行与节点行，但操作作用域没有区分，导致混乱：

- 组行的「查看」实际打开当前主库节点详情，组行的「修改配置/删除」被代理到 master 节点；
- 「备份」同时出现在组行、主库行、从库行，但接口始终按组执行；
- `1 主 0 从` 因为没有从库而不能展开，视觉上与 standalone 无法区分；
- 不可执行的操作只靠菜单变灰表达，不说明原因；
- 三点按钮的可访问名称都是「更多操作」，无法判断操作目标。

目标：用户点击前明确知道操作影响的是**整个实例组**还是**某一个节点**。

---

## 2. 核心设计原则

1. **组是父级，节点是子级。** replication 组显示父行，可展开主库/从库节点。
2. **操作按真实作用域放置。** 组级接口只在组行，节点级接口只在节点行。
3. **standalone 不制造无意义层级。** 只显示一行，菜单平铺，不做作用域分区（分区只用于 replication）。
4. **角色与实例名分离。** failover 会改变角色，UI 用实时角色徽标，不在实例名中编码角色。
5. **不可执行的操作必须解释原因**，且原因按需展开、不常驻整行。
6. **同一能力只保留一个入口。** 备份只从组进入。
7. **主按钮文案统一为「详情」**，层级差异靠角色徽标区分。
8. **节点行只放高频运维项**（启停、删除）；低频项（修改配置、调整规格）下沉到节点详情弹窗。

文案统一用「主库」「从库」，代码字段仍用 `master` / `replica`。

---

## 3. 展开规则

展开由组类型决定（`isReplicationGroup`），不依赖从库数量：

- standalone：不显示展开箭头，不渲染子行；
- replication（含 `1主N从`、`1主0从`、master 异常）：父行可展开；
- `1主0从`：展开后显示主库节点 +「当前没有从库 / 添加从库」入口，父行状态显示拓扑降级；
- 展开控件用可聚焦 `<button>`，带 `aria-expanded` 与含组名的可访问名称。

---

## 4. 操作归属矩阵

实现的最终依据。未勾选的入口不得显示在该层级。

| 操作 | standalone 行 | replication 组行 | 主库节点行 | 从库节点行 |
|---|:---:|:---:|:---:|:---:|
| 详情（打开实例/节点/组详情弹窗） | ✅ | ✅ | ✅ | ✅ |
| 编辑标签 | ✅ 平铺 | ✅ | - | - |
| 备份管理 | ✅ 平铺 | ✅ | - | - |
| 接入设置 | - | ✅ | - | - |
| 添加从库 | - | ✅ | - | - |
| 故障转移 | - | ✅ | - | - |
| 修改配置 | ✅ 平铺 | - | ✅ 详情内 | ✅ 详情内 |
| 调整规格 | ✅ 平铺 | - | ✅ 详情内 | ✅ 详情内 |
| 启动/停止 | ✅ 平铺 | - | ✅ 行菜单，受主库保护 | ✅ 行菜单 |
| 删除节点/实例 | ✅ 平铺 | - | ✅ 行菜单，受拓扑保护 | ✅ 行菜单 |
| 删除实例组 | 随唯一节点删除 | 本期不提供 | - | - |

列说明：standalone「平铺」= 菜单不分区、按序列出；节点「详情内」= 不在行菜单，改由节点详情弹窗操作区提供；节点「行菜单」= 保留在节点行三点菜单的高频项。

保护规则：

- 运行中的 replication 主库不可直接停止（原因：请先完成故障转移）；
- 主库存在从库时不可删除（原因：请先删除从库或完成拓扑调整）；
- `1主0从` 允许删除最后的主库，确认弹窗提示实例组将一并移除；
- 故障转移需至少一个健康运行从库，否则禁用（原因：没有可用从库）。

后端最终校验优先于前端预判；前端预判只用于提前解释，不替代服务端保护。

---

## 5. 菜单状态与反馈

- **禁用项**：灰化名称 + 原因触发点（? 图标），悬停/点击按需展开原因，用 `aria-disabled` 非原生元素承载（可挂 tooltip），点击禁用项不关闭菜单、不误触发。
- **执行中**：目标项显示加载态；同组互斥写操作期间相关操作禁用；完成后刷新状态。
- **危险操作**：删除固定在菜单末尾、分隔线隔开、红色文字。确认弹窗展示：对象类型（实例组/主库/从库/standalone）、组名与节点名、是否清理数据、拓扑与接入影响、不可恢复提示。
- **故障转移**：确认弹窗说明由 Sentinel 选举、不保证提升指定节点、可能短暂写中断。

## 8. 验收标准

**standalone**：只显示一行、无展开箭头；副文案「节点：实例名」；菜单平铺无分区；删除位于末尾并提示实例组一并移除；主按钮「详情」。

**`1主0从`**：父行可展开；显示主库节点 +「添加从库」；状态显示拓扑降级；故障转移禁用并说明无可用从库；主库停止禁用并说明需先故障转移；删除最后主库提示实例组一并移除。

**`1主N从`**：父行只含组级操作；主库与各从库各一行；节点菜单不含备份；节点行只含启停/删除，配置/规格在详情弹窗；主库停止/删除受保护并显示原因；从库可独立启停/删除；failover 后角色徽标更新、节点名不变。

**通用**：每个更多按钮 `aria-label` 含对象名与角色；展开/收起可键盘完成；点击复制/详情/更多不误触发父行展开；禁用项原因按需展开且读屏可读；每个能力只保留一个入口；前端构建通过。
